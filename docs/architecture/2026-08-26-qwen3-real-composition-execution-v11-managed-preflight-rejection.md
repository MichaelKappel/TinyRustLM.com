## Root Cause

The request was reconstructed by an ad hoc local transformation. Its source
object already contained the required `ownerByteLength` and `ownerSha256`
fields. The transformation also inserted unexpected sibling fields
`byteLength` and `sha256`. Build custody requires an exact source-field closure
and rejected those extras before materialization.

This is a request-materialization defect, not evidence of a managed project,
.NET SDK, environment authority, Rust output, converter, model, or receipt
contract defect. The fail-closed rejection is correct. Changing the immutable
request to make it pass would destroy the meaning of create-only evidence.
