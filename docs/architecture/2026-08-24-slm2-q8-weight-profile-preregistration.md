## Purpose

The current SLM2 F32 profile is the mechanical conversion and numerical
oracle, but a Qwen3-0.6B F32 artifact is too large for the intended local
browser path. This registration freezes the first compressed candidate before
producing any candidate bytes. It converts every exact rank-2 model matrix to
row-wise signed int8 while retaining normalization vectors and optional QKV
biases as finite little-endian F32. The KV cache stays F32 under its independent
profile.

The design follows the local converter-fidelity result that Q8 matrices plus
F32 normalization retained all substantive source first-token decisions in
the measured Qwen3-0.6B cases. That result is engineering evidence for which
profile to implement; it is not source-model quality, browser, or promotion
evidence.

## Exact Row Encoding

Every admitted Q8 tensor is rank two. `shape[0]` is the outer row count and
`shape[1]` is the row width. Each row is encoded as:

1. one positive finite little-endian binary32 scale;
2. exactly `shape[1]` signed two's-complement int8 codes in increasing column
   order;
3. no row padding and no tensor tail.

For a nonzero finite F32 source row, the scale is the correctly rounded
binary32 result of `max_abs / 127.0f32`. An all-positive-or-negative-zero row
uses the canonical `1.0f32` scale. Each source value is divided by the stored
scale with binary32 rounding, rounded to the nearest integer with halfway
cases away from zero, and clamped to `[-127, 127]`. Code `-128` is invalid.
NaN and infinity are invalid before conversion.

The tensor descriptor stores `block_elements = shape[1]`,
`block_bytes = shape[1] + 4`, and
`stored_bytes = shape[0] * (shape[1] + 4)` using checked arithmetic. The
encoding is never inferred from these lengths.

## Exact Role Policy

Q8 is required for token embeddings, an untied output projection, all Q/K/V/O
attention projection matrices, and all gate/down/up feed-forward matrices.
F32 is required for final, per-layer attention, per-layer feed-forward, and
Q/K normalization vectors plus any Q/K/V projection biases. Optional roles
remain controlled solely by the closed model flags. A role encoded with the
wrong precision is fatal even if its dimensions and bytes happen to parse.

This is an explicit mixed profile. It is not a generic `Q8`, `q8_0`, or
publisher-format alias.

## Quantization Table

The SLM2 header remains 224 bytes at exact technical version 2.0. A mixed Q8
artifact has exactly one 128-byte quantization record between the canonical
string and tensor tables. The record binds the storage, quantizer, scalar
kernel, and role-policy string identities plus every enum needed to interpret
the codes. Reserved bytes are zero. Unknown, duplicate, reordered, or partially
understood records fail closed.

The complete field offsets and enum values are frozen in the machine
preregistration. F32 reference artifacts have no quantization table; mixed Q8
artifacts require exactly one. This distinction is a closed model-level
encoding choice inside SLM2, not support for an older product format.

## Scalar Oracle

The scalar matvec oracle dequantizes one code as the binary32 product of its
stored scale and signed code, multiplies it by the corresponding binary32 input,
and accumulates from positive zero in increasing column order with a binary32
round after each multiply and add. Fused multiply-add is not part of the
oracle. Native SIMD and WASM may optimize only after meeting separately
registered numerical and token-ranking gates.

## Independent Evidence Design

The language-neutral vector document will bind the SHA-256 of a Node.js
built-ins-only implementation. That implementation must independently perform
F32-to-Q8 row conversion, complete SLM2 writing, complete SLM2 parsing, scalar
matvec, and hostile mutation generation. It may not invoke Rust, a subprocess,
or the network, and it may not consume Rust-generated output. Rust must
reproduce the independently generated bytes and all verdicts.

Vectors cover zero rows, signed extrema, positive and negative half ties,
values around half ties, rounded-scale clamping, non-power-of-two scales,
multiple-row matvec, every proper artifact prefix, and every registered hostile
descriptor or payload class.
