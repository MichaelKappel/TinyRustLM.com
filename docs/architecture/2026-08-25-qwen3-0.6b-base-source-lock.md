# Qwen3-0.6B Base Source Lock

## Decision

`contracts/vnext/qwen3-0.6b-base-source-lock.v1.json` is the sole current
content authority for converting the reviewed upstream `Qwen/Qwen3-0.6B`
checkpoint at immutable revision
`c1899de289a04d12100db370d81485cdf75e47ca`. The canonical lock is 1,901 bytes
with SHA-256
`e24bf9d95a5631e0b7c44c192e4ec6b7ec4b8793e1597f9dad99f1257ecf582d`.

The lock contains no machine-local source path. It binds nine safe basenames,
their exact lengths, and their SHA-256 identities. Their aggregate source size
is 1,519,207,688 bytes. The source directory used by an execution must contain
exactly those nine direct regular files and no additional member, symlink, or
reparse point. The converter independently rehashes the closure before reading
model tensors and again before promotion.

The `config.json`, `merges.txt`, `tokenizer.json`, `tokenizer_config.json`, and
`vocab.json` records are byte-identical to the already accepted
`qwen3-0.6b-tokenizer2-source-lock.v1.json` records. The configuration, model,
and tokenizer records also match the base identities frozen before output in

enforces both relationships and the closed JSON shape.

The lock records the Apache-2.0 SPDX identity and the reviewed
`redistribution-and-conversion-approved` disposition required by the converter.
It does not replace the bundled license file, model-card review, source-screen
evidence, derivative training provenance, or later release authorization.

## Claim Boundary

This checkpoint proves only that one complete local source closure has a
public, path-free, immutable content identity suitable for a registered
conversion attempt. No complete conversion was executed while creating this
lock. No SLM2, Tokenizer2, Template2, Sampling2, Prompt2, ACG2, runtime,
browser, quality, P2P, catalog, deployment, or campaign result follows from
the lock.

The unchanged upstream base remains terminally rejected as a product model.
It is permitted only for conversion and runtime parity work and as provenance
for a later independently qualified derivative. Campaign counters remain
`0/20`, `0/50`, `0/25`, `0/40`, and `0/20`.
