# Safetensors Candidate Review Memory

`review-safetensors-candidate` adds a no-crate pre-extraction review artifact for real trained safetensors checkpoints, and the extraction, conversion, and browser-bundle commands can now consume that artifact as their final review-bound argument.

The command accepts an input safetensors file, target source shape, output quantization, source model id, source model SHA, source config checksum, source tokenizer checksum, source license route, output review path, optional reference prompt route, reference output checksum, eval-cases route, source config route, and source tokenizer route. Source model SHA must be a 40-hex SHA-1 or 64-hex SHA-256 value, optionally prefixed with `sha1:` or `sha256:`.

The printed `tinyrustlm-slm-pack` primary usage text now advertises the full candidate-review source-config/source-tokenizer tail plus the optional candidate-review tails for extraction, conversion, and browser bundling. The `primary_usage_lists_review_bound_safetensors_tails` test keeps the displayed handoff route aligned with the parser accepted forms.

The review report records source file, source/config/tokenizer identity, hex64 config/tokenizer/reference-output checksums, optional config and tokenizer artifact routes, local JSON artifact status/kind/checksum/byte/detail evidence when those routes resolve to files, manifest-ready tokenizer import status/count/checksum rows, local license/reference-prompt/eval-case artifact status/kind/checksum/byte/detail evidence when those routes resolve to files, header checksum, tensor-directory checksum, source-plan mapping checksum, architecture family, tensor-layout strategy, tokenizer strategy, quantization target, parameter count, matched tensor count, raw source bytes, target estimated serialized `.slm` bytes using writer alignment rules, BPE tokenizer section byte accounting for `manifest-bpe-v1` source shapes, comparative f32/q8_0/q4_0 byte estimates, per-quantization selector fit status, `browser_admission_default_strategy=browser-frugal-quantized`, `browser_admission_preference_order=q8_0,q4_0,f32`, browser-admission preferred and fallback quantization fields, context token limit, KV-cache byte/page budget, conversion status, converter gap status, reference-output route, runtime-smoke placeholder route, eval-cases route, eval-sidecar placeholder route, and `required_next_gate=extract-raw-f32-tensors`. BPE source-shape reviews now require a checksum-matched local compatible BPE tokenizer JSON artifact, so exact estimates use imported token and merge rows instead of template tokenizer rows.

When config or tokenizer routes resolve to local JSON, the review parses the artifact, requires the supplied checksum to use the `0x` plus 16-hex TinyRustLM format and match the local text checksum, records artifact evidence rows, and writes normalized detail rows. The optional reference-output checksum uses the same hex64 format. Config detail echoes `model_type`, vocab size, hidden size, layer count, attention heads, KV heads, FFN size, and max context when present. Tokenizer detail echoes tokenizer version, `model.type`, BPE vocab entry count, max token id, merge count, added-token count, and normalizer/pre-tokenizer/decoder/post-processor component summaries, and `manifest-bpe-v1` shapes require tokenizer JSON with `model.type=BPE`, numeric `vocab` ids, and `merges`. Local license routes record checksum, byte count, and line count. Local reference prompt routes record checksum, byte count, and line count. Local eval-case routes parse the eval manifest, require version 1 with a positive case count, and record checksum, byte count, scope, and case count. Compatible local BPE tokenizer JSON uses raw byte fallback ids for merge inputs, leaves TinyRustLM special ids reserved, and emits custom token bytes plus ranked merges into the source manifest; byte-level remapping tokens are rejected before extraction.

Review-bound extraction recomputes the source plan and requires the review version/layout, source path, target model shape, file/header/tensor-directory checksums, source-plan mapping checksum, matched tensor count, raw source bytes, conversion status, and `required_next_gate=extract-raw-f32-tensors` to match before tensor bytes are copied. It also requires reviewed source/config/tokenizer/license/reference/eval routes instead of the pending placeholders, revalidates local config/tokenizer/license/reference-prompt/eval-case artifact rows including normalized detail when present, recomputes tokenizer import status/count/checksum rows, recomputes budget rows with the same imported tokenizer rows, then writes `source_review_kind=safetensors-candidate-review`, `source_review_status=validated-before-extraction`, `source_review_checksum`, `source_review_required_next_gate=extract-raw-f32-tensors`, and imported `tokenizer=bpe-v1` rows into the raw `source.manifest` when a compatible BPE artifact was reviewed.

Review-bound conversion requires the requested f32/q8_0/q4_0 output to match the review's `quantization_target`. Review-bound browser bundling requires the requested quantization to match `browser_admission_preferred_quantization`, while `all` remains accepted when the review identifies a browser-fit preferred quantization. It also resolves the review's local `eval_cases_route` when no explicit eval file is supplied, rejects an explicit eval file that does not canonicalize to the reviewed route before extraction, appends the reviewed route into generated eval sidecars, and makes the browser compare that sidecar route to the fetched source review before model bytes. When f32 exceeds the selector budget, the review now chooses q8_0 first when it fits and q4_0 only when q8_0 also exceeds the selector budget.

This moves real-checkpoint work forward without writing source directories, converted `.slm` files, browser roots, or assistant-quality claims before reviewed source/config/tokenizer/license/reference/eval routes exist, then keeps the downstream commands bound to that review when it is supplied. Browser admission carries the copied source review fields and candidate-scoped `converted-trained.source.review` route through admission and selector registry evidence, the BPE fixture path proves review-bound q8_0 bundle admission with explicit eval evidence and `BPE1` model bytes, the reviewed local BPE pipeline proves all-quant browser admission from inspect/plan/review through selector validation, the eval-route drift tests prove browser bundle evidence and fetched eval sidecars cannot silently diverge from `eval_cases_route`, local license/prompt/eval artifact drift tests prove reviewed file-backed route bodies remain checksum-bound, tokenizer-import drift tests prove imported BPE rows remain checksum-bound, and browser source-review smoke now renders or rejects reviewed model id, SHA-shaped source revision, config/tokenizer checksums, tokenizer import evidence, license route, reference prompt, reference output checksum, and eval route before model bytes.
