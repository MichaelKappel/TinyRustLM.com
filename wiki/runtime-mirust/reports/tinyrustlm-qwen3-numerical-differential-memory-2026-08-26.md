## Exact Proof And Failure Semantics

The source-to-reconstructed arrow isolates conversion and quantization
difference. The reconstructed-to-Rust-scalar arrow isolates packed-Q8
interpretation and scalar runtime mathematics. A later accepted Rust scalar
result must still be compared separately to every optimized native and
browser-WASM implementation. No arrow is transitive.

The trace stores binary32 stages in fixed semantic order. The verifier applies
preregistered per-arrow defaults and exact stage overrides for maximum absolute
error, maximum relative error with positive floor, normalized RMSE, cosine
similarity, sign disagreement above a floor, maximum ULP distance, top-k logit
overlap, and greedy token identity. Tolerance search or loosening after output
is forbidden.

Every future output root is create-only. The terminal manifest is written
last. Partial output remains immutable without a completed manifest. A launch,
timeout, crash, resource-bound failure, source drift, environment drift, model
drift, trace drift, verifier rejection, or ambiguous observation closes that
operation. It cannot be repaired, retried, resumed, overwritten, deleted,
adopted, or relabeled.
