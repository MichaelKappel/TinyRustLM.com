## Implementation

Each converted-trained browser bundle entry now copies the reviewed `source.manifest` into its generated evidence lane as `evidence/<candidate-id>/converted-trained.source.manifest` after source conversion succeeds. When the raw source manifest is review-bound, it also copies the original candidate-review report into `evidence/<candidate-id>/converted-trained.source.review`.

The generated admission now carries `source_manifest_path`, `source_manifest_checksum`, `source_manifest_kind=trained-source-manifest`, and `source_manifest_status=reviewed-source-snapshot`. When the copied source manifest includes a safetensors candidate review, the same admission also carries `source_review_kind=safetensors-candidate-review`, `source_review_path=../evidence/<candidate-id>/converted-trained.source.review`, `source_review_status=validated-before-extraction`, `source_review_checksum`, and `source_review_required_next_gate=extract-raw-f32-tensors`. Every converted-trained entry now also writes `evidence/<candidate-id>/converted-trained.source.validation` with `source_validation_gate=validate-source`, `source_validation_status=pass`, `source_manifest_checksum`, source identity, tensor count, tied-output flag, optional source-review checksum, and `required_next_gate=convert-raw-f32-source-to-slm`; admission and selector registry carry `source_validation_path` plus checksum.

`selector.registry` copies the source-manifest, optional source-review, and source-validation fields into the matching entry only when the routes are `../evidence/<candidate-id>/converted-trained.source.manifest`, `../evidence/<candidate-id>/converted-trained.source.review`, and `../evidence/<candidate-id>/converted-trained.source.validation`, validates checksum/kind/status drift against the admission source route, and binds review path plus checksum into the heritable artifact identity when present.

The browser selector intake accepts those optional fields, then fetches and checksum-verifies the reviewed source manifest, candidate-review sidecar, and source-validation sidecar before requesting converted `.slm` bytes. It verifies that fetched `source_review_*` fields match the selector-carried review identity, checks the review sidecar version/layout/target shape/next gate, requires reviewed source model id, SHA-shaped source revision, config/tokenizer checksums, license route, reference prompt route, reference output checksum, and eval route, and rejects a selector that omits review fields while the fetched source manifest has them. After source review succeeds, the browser fetches `converted-trained.source.validation`, verifies that it binds back to the selected source manifest checksum, source identity, tensor count, tied-output flag, optional source-review checksum, and next conversion gate, then fetches `converted-trained.runtime`, verifies the selector-carried runtime sidecar checksum and runtime-smoke fields, then fetches eval evidence and requires the eval sidecar `eval_cases_route` to match the fetched source review before model bytes. `converted-trained-source-manifest-drift` proves a changed source manifest body stops q8 loading at `source manifest checksum mismatch`, `converted-trained-source-review-drift` proves checksum-matched review-field drift stops at `source review identity field source_review_checksum`, `converted-trained-source-review-sidecar-drift` proves checksum-matched fetched report field drift stops at `source review field source_model_sha`, `converted-trained-source-review-omitted` proves selector omission stops at `source review identity missing from selector`, `converted-trained-source-validation-drift` proves validation field drift stops before runtime/eval/model bytes, `converted-trained-runtime-evidence-drift` proves runtime sidecar drift stops before eval or q8 bytes, and `converted-trained-source-review-eval-route-drift` proves review/eval route mismatch stops at eval verification, all before q8 model bytes are requested.

The snapshot is written for single-quant and all-quant browser roots, including safetensors-generated roots. It preserves the reviewed source identity next to the compatibility, lineage, candidate, promotion, runtime, eval, and admission sidecars while making the browser verify the source breadcrumb before model use.
