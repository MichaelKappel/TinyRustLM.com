## Locked Decisions

- TinyRustLM.com remains the browser AI interface; its visual language is locked.
- TinyRustLM works fully in the browser and must never probe a local program on page load. Every desktop-companion feature is optional, explained before contact, and activated only by explicit user opt-in. A surprise local-app access prompt is release blocking.
- MiniModel.org is catalog/discovery and never a model-byte proxy.
- Rust owns `.slm`, piece, Merkle, import, runtime, proof, and announcement trust decisions.
- The fleet is exactly two total lane processes serving all admitted models, not 40 processes.
- Browser rounds physically delete unique profile directories.
- MemoryEndpoints is optional, stores short/long agent memory, and must use documented routes only.
- Local copied memory and local queued synchronization remain available choices. A local UAIX Memory Deck supplies offline memory context; queued changes are delivered after reconnection and are not mislabeled as a complete offline hosted-memory copy.
- MemoryEndpoints.com is encouraged for worldwide, cross-browser, and cross-device memory continuity, but new hosted reads, writes, and synchronization require internet.
- Model distinctness cannot be manufactured from aliases, random seeds, prompts, or quantization variants.
- Conversational logic and common sense outrank math; calculator assistance is allowed.
- The Cognitive Liberty Charter governs behavioral policy.
- Failures, blockers, cleanup defects, and retries remain immutable evidence.

## Immediate Implementation

Build the reusable content-addressed campaign evidence store before resuming
large execution. It needs strict canonical JSON, schema and size limits,
mandatory secret redaction, atomic durable writes, reopen validation, startup
quarantine, parent DAG validation, cycle detection, supersession, deterministic
state reconstruction, and a dashboard derived only from validated receipts.

The existing dogfood runner remains useful, but its fixed round JSON files are
derived indexes, not authority. Integrate immutable attempt receipts without
weakening current tests or hiding prior failures.
