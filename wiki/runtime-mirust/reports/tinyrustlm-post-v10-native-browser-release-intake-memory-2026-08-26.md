### Composition And Numerical Proof

The exact composition members are `model.slm2`, `tokenizer.tokenizer2`,

### Non-Weight Semantics

Tokenizer2, Template2, Sampling2, and Prompt2 are declarative composition
members. Do not evaluate arbitrary Jinja or publisher script. Keep trusted
template markers separate from identical untrusted text. Specify every
sampling default, RNG, tie order, stop condition, termination reason, context

generation.

### Browser

The dedicated worker owns model, tokenizer, KV, and generation state. UI and
worker commands bind composition, conversation, turn, generation, message, and
sequence identities. Exactly-once rendering deduplicates event identity, not
repeated token text. Cancellation stops real work; a terminated worker and its
KV state are discarded. A fresh worker reopens and reverifies immutable bytes.

Measure every model/storage/WASM/JS/KV/scratch/message/browser memory component
and every copy. OPFS is not proof of zero-copy. A fixed 1.5 GiB budget,
universal Memory64 penalty, browser support table, and Relaxed SIMD speedup are
unverified report assertions. Use a deterministic explicit first kernel
profile. Do not transparently switch to another kernel or runtime.

A fresh profile means actual process/context closure and deletion of an owned
persistent profile with containment and reparse defenses. Reload and storage
clears do not count. Real Chromium is required before a browser claim; Node is
not browser evidence.
