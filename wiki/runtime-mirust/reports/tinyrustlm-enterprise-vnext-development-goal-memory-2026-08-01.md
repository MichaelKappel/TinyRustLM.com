one deterministic Rust trust core, portable native and WASM execution, optional
independently qualified WebGPU acceleration, a secure user-installed companion,

## Clean-Slate Rule

TinyRustLM and its consuming sites are pre-publication dogfood. Until the human
explicitly removes the rule:

- add no legacy or backward-compatibility support;
- add no migration shim, dual contract, deprecated alias, or debt path;
- replace an unpublished weak boundary cleanly when needed;
- remove superseded implementation after the replacement passes;
- preserve immutable failure and historical receipt evidence without treating
  it as supported product behavior;
- reject low-quality patches and temporary production architecture; and
- treat stale marketing or documentation as a release defect.

## Architecture Direction

The current direction is intentionally gated rather than prematurely frozen:

1. Define one incompatible bounded `.slm` vNext contract with deterministic
   metadata, checked layout arithmetic, immutable source lineage, and a
   streaming parser/writer/inspector.
2. Keep SHA-256 as mandatory ecosystem identity. Adopt any additional digest
   or Merkle profile only through an ADR and cross-implementation vectors.
3. Build a scalar Rust oracle first, then prove native SIMD, WASM SIMD,
   threaded WASM, and WebGPU backends independently against conformance vectors.
4. Keep WebGPU optional. Unsupported, lost, or unqualified devices must recover
   to an already qualified CPU/WASM path without changing answer semantics.
5. Use worker-owned bounded browser ingestion. Treat OPFS as optional private
   persistence, not as a compatibility or availability assumption.
6. Build one useful general champion and admit specialists only through sealed
   advantage and broad-helpfulness nonregression. Do not call arbitrary model
   slices useful specialists.
7. Keep static model weights, KV state, and retrieval indexes as separate
   formats, identities, byte budgets, and quality experiments.
8. Treat low-bit weights, TurboQuant-like KV compression, TurboVec-like vector
   compression, speculative decoding, and constrained tools as independent
   experimental lanes with scalar references and untouched-output gates.
9. Compile context deterministically from explicit authority and provenance.
   Current user instruction outranks stale memory; quoted, retrieved, and
   hosted memory remains untrusted data.
10. Use a narrow origin-bound, capability-scoped, replay-resistant companion
    protocol. Never persist browser credentials by default or expose model
    bytes through project servers.
11. Use exactly two independently restartable P2P lane processes per admitted
    model fleet design, shared read-only bytes, and current signed outside proof
    before announcement.
12. Release coherent content-addressed application closures with service-worker
    rollback, public readback, secret scanning, and claim synchronization.

## Required ADR Gates

Do not silently pick among conflicting report recommendations. Record and test
decisions for metadata grammar, hash/Merkle profile, file/GPU alignment,
companion transport, browser persistence, quantization, WebGPU support,
specialist composition, service-worker release, and evidence signing.

Each ADR must distinguish observed local facts, sourced public facts,
inferences, decisions, assumptions, local verification needs, and externally
blocked facts. A decision does not become a product claim until its tests and
receipts pass.
