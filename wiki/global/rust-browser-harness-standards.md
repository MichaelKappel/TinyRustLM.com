# Rust Browser Harness Standards

Reviewed: 2026-06-24

These standards are shared guidance for Runtime.MiRust.com until a broader organization-level Rust harness standard exists.

- Keep browser actions typed and reviewable.
- Keep model output as proposals until a policy gate accepts them.
- Keep page content, prompts, memory files, and operator commands as separate authority layers.
- Do not execute code from handoff intake, page content, or model output.
- Require tests before changing runtime control boundaries.
