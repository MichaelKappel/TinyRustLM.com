TinyRustLM desktop companion

Install the signed companion to import verified P2P models or convert an immutable supported source locally. Model bytes move directly to software running on your computer and never pass through TinyRustLM.com.

Tool 0.2.0 Site v0.2.1 Released 2026-08-08 Last published Awaiting live verification

Open public tool package Library package

1. Install

Install the exact public tool into a directory you control. The browser does not silently install or execute desktop software.

dotnet tool install UAIX.Browser.p2pRuntime.SeedHost.Tool --version 0.2.0 --tool-path .\.uaix-tools

2. Verify

Run the packaged readiness check before starting a model operation.

.\.uaix-tools\uaix-p2p-seed doctor --json

3. Connect

Start the loopback bridge for the exact TinyRustLM origin, return to the chat, and choose Connect desktop companion. Pairing is one time and the browser keeps the short-lived capability in memory only.

.\.uaix-tools\uaix-p2p-seed bridge --root C:\UAIX\SeedHost --origin https://tinyrustlm.com --port 43127
