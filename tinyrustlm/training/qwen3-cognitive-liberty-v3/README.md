# Qwen3 Cognitive Liberty Training v3

This lane combines the 40-record v2 practical and charter corpus with a
strictly selected 60-record positive rehearsal subset. The rehearsal data
preserves ordinary conversation, factual answers, transformations, exact
formats, current-turn state, and trustworthy memory behavior without importing
the old refusal, generic-uncertainty, arithmetic, ambiguity, or injection sets.

The resulting 100-record corpus contains four narrow refusal boundaries.
Promotion still requires fixed and seeded behavioral improvement over the
unadapted Qwen3-0.6B source model.
