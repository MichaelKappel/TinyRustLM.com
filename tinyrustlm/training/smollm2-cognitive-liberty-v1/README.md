# SmolLM2 Cognitive Liberty Quality Tier v1

This lane evaluates `HuggingFaceTB/SmolLM2-1.7B-Instruct` as an optional
higher-quality local tier. It uses the same 100-record balanced corpus as the
Qwen3 v3 lane and a shorter model-specific Cognitive Liberty system prompt.

The larger footprint is acceptable only if fixed and seeded conversation gates
show a material quality improvement. This lane does not replace the compact
Qwen3 tier merely because it has more parameters.
